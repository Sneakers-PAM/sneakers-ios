# sneakers-ios 🕊️

> 🧭 Sneakers iOS app (Swift)

## 🛠 Develop

```bash
task lint     # SwiftLint and SwiftFormat check
task format   # apply SwiftFormat
task test     # swift test for a package, xcodebuild test for an app
task license  # check Apache-2.0 headers (golic)
```
